## What You Learn Here

After this section, you can:
- Explain what DevOps is in simple words
- Navigate a Linux server using the terminal
- Write Bash scripts to automate tasks
- Read and write YAML and JSON files
- Use Git to manage your code

---

## Why These Topics Matter

Every DevOps tool runs on Linux. Every config file is YAML or JSON.
Every team uses Git. These are not optional — they are the foundation.

---

## Interview Tip

In a 45-minute interview, you will spend the first 5 minutes talking about your background.
Know your tools. Know why you use them. Be ready to write a Bash script live.
